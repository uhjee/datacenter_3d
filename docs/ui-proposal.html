UI 개선안 — 우측 패널 중심

지금 구성(좌측 조작 · 가운데 3D · 우측 정보 · 아래 흐름도)은 그대로 두고, 보이는 방식만 바꾸는 안입니다. 우측 패널은 "글을 읽는 패널"에서 "한눈에 상태를 보고, 궁금하면 펼쳐 읽는 패널"로 바꿉니다. 장비 카드와 지표 탭의 숫자는 현재 시뮬레이터 값(IT 부하 100%, 외기 15°C)이고, 랙과 시나리오 시안의 숫자는 예시입니다.

1. 지금 무엇이 불편한가 현재 화면 점검

위계모든 줄이 같은 무게

제목(h4) · 이름-값 목록 · 설명 문단이 같은 글자 크기와 색으로 이어집니다. UPS-A 카드에서 가장 중요한 "부하율 48%"는 지표 탭에 가야 보이고, 정보 탭에는 숫자가 하나도 크지 않습니다.

길이스크롤이 너무 깁니다

UPS-A는 하류 14줄이 같은 모양으로 나열되고(PDU-A1-1 … A2-6), 그 아래 추적 · 묶음 · 성능 포인트 · 설명 · 같은 유형이 모두 펼쳐져 있습니다. 화면 두 장 이상을 내려야 끝납니다.

구분데이터와 학습용 설명이 섞임

role · detail · hint · note 문단이 실제 값 사이사이에 끼어 있어, 상태를 보러 온 사람과 공부하러 온 사람 모두에게 방해가 됩니다.

색노란색이 너무 많은 뜻을 가짐

선택된 버튼, 층 번호, 탭, 시나리오 칩, 배터리 색이 모두 노란 계열입니다. 노란색이 "지금 고른 것"이라는 신호로 읽히지 않습니다.

구조관계가 그림이 아니라 목록

"받는 곳 · 보내는 곳"이 목록이라 상류 → 이 장비 → 하류의 방향이 눈에 바로 들어오지 않습니다. 랙도 42U 중 어디에 무엇이 있는지 숫자로만 나옵니다.

일관성상태 표현이 탭마다 다름

지표 탭은 ✓ 배지와 게이지, 시나리오 탭은 테두리 글자 태그, 정보 탭은 글자만 씁니다. 같은 "정상 · 주의 · 위험"이 세 가지 모양입니다.

2. 기준으로 삼을 원칙 관제 화면 · 속성 패널 사례에서

ISA-101 고성능 HMI바탕은 차분하게, 색은 상태에만

배경 · 장비는 무채색, 색은 이상 상태와 계통(A/B · 전원 출처)에만 씁니다. 노란색은 "선택 · 초점" 하나의 뜻으로 줄입니다.

대시보드 타일큰 숫자 + 보조 숫자 + 기준선

패널 맨 위에 그 대상의 핵심 수치 2~3개를 타일로 둡니다. 타일 하나 = 값 · 단위 · 기준 대비 막대. 5~7개를 넘기지 않습니다.

점진적 공개요약은 펼쳐 두고, 자세한 것은 접어 둠

상태 → 관계 → 속성 → 설명 순서로 내려가고, 설명 · 같은 유형 · 개념은 기본으로 접습니다. 접힌 제목에 개수를 보여 열기 전에 양을 알 수 있게 합니다.

디지털 트윈 뷰어선택한 대상의 정체부터

머리 영역에 아이콘 · 이름 · 위치 경로(B1 › UPS실 A) · 상태 알약 · 아이콘 버튼을 고정합니다. "무엇을 보고 있는지"가 스크롤해도 사라지지 않게 합니다.

학습용 도구설명은 따로 보이는 상자에

교육용이라 설명을 없애지 않습니다. 대신 파란 "알아보기" 상자와 ? 아이콘으로 모양을 분리해, 읽을지 말지를 사용자가 고르게 합니다.

숫자 가독성고정폭 숫자와 단위 분리

숫자는 tabular-nums로 자릿수가 흔들리지 않게 하고, 단위는 작고 흐리게 붙입니다. 시나리오처럼 값이 계속 바뀌는 곳에서 특히 효과가 큽니다.

3. 우측 패널 시안 너비 360px 그대로

네 장 모두 같은 부품(머리 영역 · KPI 타일 · 상태 알약 · 접는 섹션 · 알아보기 상자)으로 만듭니다. 부품을 한 번 만들면 탭과 장비 종류가 늘어나도 모양이 흐트러지지 않습니다.

좌측 패널섹션을 접는 아코디언으로, 체크박스 → 토글 스위치(영역 색 점 포함). 접힌 제목에 현재 값(예: 랙 색칠 · 없음)을 보여 열지 않아도 상태를 앎.
층 이동좌측의 층 버튼(전체 · PH … B1)을 3D 화면 왼쪽 아래 떠 있는 바로 옮겨 3D와 붙여 둠. 좌측 패널은 "무엇을 보일지"만 담당.
3D 위 조작오른쪽 위에 확대 · 축소 · 전체 보기 아이콘 버튼 묶음. 반투명 배경 + 흐림(backdrop-blur)으로 3D를 가리지 않게.
흐름도노드 카드를 우측 패널과 같은 머리 모양(아이콘 · 이름 · 층)으로 맞추고, 선택 노드만 노란 테두리.
공통 토큰면 3단계(s1 · s2 · s3), 선 2단계, 글자 3단계, 모서리 8 · 10px, 간격 4px 배수. 노란색은 선택 · 초점 전용, 상태색(정상 · 주의 · 위험)은 아이콘과 함께만.
