# 데이터센터 3D 시뮬레이터

빌딩형 데이터센터(지하 1층 ~ 옥상)의 **전력 · 공조 계통**을 3D로 살펴보는 교육용 웹 시뮬레이터입니다.
장비를 눌러 성능 포인트와 연결을 보고, 전기와 냉기의 길을 따라가고, 서버실 온도와 고객사 계약을 확인하고, 사고 시나리오를 시간 순서대로 재생합니다.

> 수치는 장비 성능 포인트와 단순화한 모델로 계산한 **근사값**입니다(온도 분포는 CFD가 아닙니다). 경향을 이해하는 용도이며 설계 · 운영 판단에 쓰지 마세요.

## 실행

Node.js 18 이상이 필요합니다.

```bash
npm install
npm run dev        # http://localhost:5173
```

| 명령 | 설명 |
|---|---|
| `npm run dev` | 개발 서버 |
| `npm run build` | 타입 검사 후 `dist/`에 빌드 |
| `npm run preview` | 빌드 결과 미리보기 |
| `npm run typecheck` | 타입 검사만 |

| 위치 | 내용 |
|---|---|
| 상단 바 | 검색 │ **보기** [온도] [도면] │ **학습** [시나리오] [가이드 투어] │ 좌우 패널 열고 닫기 |
| 왼쪽 패널 | [탐색] 장비 목록(설비 / 랙 트리) · [표시] 레이어 · 연결선 · 랙 색칠 · 계통 묶음 |
| 3D 영역 | 왼쪽 층 막대 · 오른쪽 위 카메라 막대 · 왼쪽 위 온도 카드(온도 보기 중) · 아래 가운데 활성 상태 칩 줄 |

제목 옆 ⓘ에 마우스를 올리면 그 기능의 사용법 · 기준 · 범례가 나옵니다.

## 기능

### 3D 빌딩
- 층 막대: [전체] 또는 층 하나만 보기, 층 벌려 보기 / 겹쳐 보기.
- 서버실 2곳: 3F 서버실 A(공냉식 · 열복도 봉쇄), 4F 서버실 B(수냉식 · 봉쇄 없음), 랙 416대.
- 레이어로 전력 · 공조 · IT 랙 · 케이지 · 방재 · 보안 · 연결선 · 샤프트 · 벽체 · 실 이름을 켜고 끈다.
- 랙 색칠: 공간(U) · 전력 사용률 · 흡기 온도.

### 장비 정보 · 연결 추적
- 장비 · 랙을 누르면 오른쪽에 정보 카드(운전 상태, 핵심 수치, 성능 포인트, 연결)가 열린다. 랙은 42U 입면 · rPDU-A/B · 흡기 온도.
- 연결: 받는 곳 · 보내는 곳, **상류 · 하류 추적**으로 경로 전체를 3D · 도면에서 강조.
- 계통 묶음(A계통, UPS 조, 냉매 쌍 등)을 고르면 그 장비와 연결만 남기고 흐리게 표시.

### 하단 도면
- [도면]으로 열고 닫는다. 전력 단선도 · 공조 흐름도, 3D 선택과 연동(도면에서 고르면 3D가 그 장비로 이동).

### 온도 보기 (히트맵 · 기류 입자 · 2D 상면도)
- 상단 [온도]로 켜면 서버실 바닥에 고른 높이(하 0.3 · 중 1.1 · 상 1.9m) 단면의 온도 분포가 깔리고, 하단에 2D 상면도가 열린다.
- 온도 카드: 서버실 A/B, 표시(히트맵 · 기류 입자), 시점(위에서 · 통로 단면), 단면 높이, 구간별 온도 바(15~40°C, ASHRAE 권장 18~27 · 허용 32°C), 펼치면 컨테인먼트 · 블랭킹 · 급기 온도 · 수치.
- 2D 상면도: 랙 흡기 · 배기 · ΔT 값과 색, 핫스팟 목록, 항온항습기 상태(고장 ✕), [비교]로 봉쇄 방식을 바꿨을 때를 나란히.
- 3D 바닥 · 2D 빈 곳을 가리키면 그 지점 공기 온도, 랙을 가리키면 하 · 중 · 상 흡기 · 배기.

### 고객사 · 계약
- 서버실 B 증설 블록을 고객사 A~D에 임대(A · B는 케이지, C · D는 랙 단위).
- 케이지 철망 · 고객사 이름표를 누르면 고객사 카드: 계약 전력 대비 유효 전력, 30일 추이(월 최대 수요), 랙별 A/B 회로 여유, 흡기 온도 SLA, 계약 조건.
- 지표 탭 '고객사 계약 전력'과 [주의] 탭에도 초과 · 주의가 모인다.

### 지표 · 용량 / 주의
- 지표: PUE와 분해, IT 부하율 · 외기 온도 조절, 서버실별 냉각(N+1) · 전력 · 공간 남은 용량, UPS 2N 부하율, A · B 비교.
- 주의: 흡기 권장 초과 랙, 냉각 N+1 부족, UPS 50% 초과 · 2N 깨짐, 고객사 계약 초과 · 회로 여유 부족, 시나리오 중 정지한 랙. 누르면 그 대상으로 이동.

### 사고 시나리오
- 한전 완전 정전 · 한전 1회선 정전 · UPS 고장 · 항온항습기 고장 · 누수 · 배터리실 화재 · 서버실 화재.
- 재생 · 일시정지 · 속도(1 ~ 20배) · 진행 단계 이동, 조건 바꾸기. 공조 시나리오는 시작하면 온도 보기가 함께 켜진다.

### 가이드 투어
- 전기(한전 → 랙)와 열(랙 → 옥상)의 길, 온도 보기, 고객사 계약, PUE까지 18단계. ← → 이동, Esc 종료.

## 조작

| 조작 | 동작 |
|---|---|
| 드래그 / 우클릭 드래그 | 회전 / 이동 |
| 휠 | 마우스가 가리키는 쪽으로 확대 · 축소 |
| 더블클릭 | 그 지점을 회전 중심으로 |
| 클릭 (3D · 2D) | 선택만 (카메라는 그대로) |
| 목록 · 표 · 도면에서 고르기 | 선택하고 3D 카메라를 그 자리로 이동 |
| 정보 카드의 ⌖ · 2D 랙 더블클릭 | 그 장비 · 랙으로 카메라 이동 |
| ⌘K / Ctrl+K | 전체 검색 (장비 · 랙 · 고객사 · 계통 · 층 · 시나리오 · 보기) |

카메라 막대(3D 오른쪽 위): **홈**(처음 화면으로: 보기 설정 · 층 · 레이어 · 선택 · 시나리오 모두 초기화) · **화면 맞춤**(선택한 층 기준) · **링크 복사** · 확대 · 축소 · ⓘ 조작 안내.

활성 상태 칩 줄(3D 아래 가운데): 지금 켜진 시나리오 · 온도 보기 · 층 · 추적 · 묶음 · 랙 색칠을 보여 주고 ✕로 바로 끈다. 층 칩의 [장비 강조]로 그 층 장비만 강조.

## 설정 기억 · 장면 링크

- 레이어 · 연결선 · 랙 색칠 · 보기 방식 · 공조 조건 · 운전 조건 · 히트맵 설정은 브라우저에 저장되어 새로고침해도 유지된다.
- 층 · 선택 · 온도 보기 · 도면은 주소 `#`에 담긴다(예: `#floor=4F&sel=rack:B-6-36`, `#temp=A`). 링크 복사 버튼으로 보내면 같은 장면으로 열린다.
- 홈 버튼은 저장된 설정까지 처음 상태로 되돌린다.

## 기술 구성

Vite · React 19 · TypeScript · three.js(@react-three/fiber, drei) · Zustand · lucide-react

- 3D는 변화가 있을 때만 그린다(`frameloop="demand"`). 정적인 장비 형상은 같은 재질 부품을 합쳐 그린다(`scene/merge.tsx`).
- 개발 서버에서 `?kit`를 붙이면 UI 공통 부품 미리보기, 콘솔에서 `__view`(화면 상태) · `__three`(렌더러)로 상태를 볼 수 있다.
