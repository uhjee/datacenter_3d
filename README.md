# 데이터센터 3D 시뮬레이터

빌딩형 데이터센터(지하 1층 ~ 옥상)의 **전력 · 공조 계통**을 3D로 살펴보는 교육용 웹 시뮬레이터입니다.
장비를 클릭해 성능 포인트와 연결을 보고, 전기와 냉기가 어디서 와서 어디로 가는지 따라가며, 사고 시나리오를 시간 순서대로 재생할 수 있습니다.

> 수치는 장비 성능 포인트와 단순화한 모델로 계산한 **근사값**입니다. 경향을 이해하는 용도이며 설계 · 운영 판단에 쓰지 마세요.

## 주요 기능

- **3D 빌딩** — 층 벌려 보기 / 겹쳐 보기, 층 이동, 서버실 2곳(공냉식 · 수냉식, 랙 432대)과 전력 · 공조 장비
- **연결 추적** — 상류 · 하류 추적, 계통 묶음(A계통, 냉매 쌍 등)으로 강조
- **흐름도(2D)** — 전력 단선도 · 공조 흐름도, 3D 선택과 연동
- **기류 · 온도** — 봉쇄 · 블랭킹 · 급기 온도에 따른 랙 흡기 온도
- **지표 · 용량** — PUE, 서버실별 냉각 · 전력 · 공간 남은 용량, UPS 2N 부하율
- **사고 시나리오** — 한전 완전 정전, 한전 1회선 정전, UPS 고장, 항온항습기 고장, 누수, 배터리실 화재, 서버실 화재
- **가이드 투어** — 전기가 한전에서 랙까지, 열이 랙에서 옥상까지 가는 길을 16단계로 안내

## 실행

Node.js 18 이상이 필요합니다.

```bash
npm install
npm run dev        # http://localhost:5173
```

| 명령 | 설명 |
|---|---|
| `npm run dev` | 개발 서버 |
| `npm run build` | 타입 검사 후 `dist/`에 빌드 |
| `npm run preview` | 빌드 결과 미리보기 |
| `npm run typecheck` | 타입 검사만 |

개발 서버에서 `?kit`를 붙이면(`http://localhost:5173/?kit`) UI 공통 부품만 따로 볼 수 있습니다.

## 기술 구성

Vite · React 19 · TypeScript · three.js(@react-three/fiber, drei) · Zustand · lucide-react

## 폴더 구조

```
src/
  data/       건물 · 장비 · 랙 · 연결 데이터, 온도 · 지표 모델
  scene/      3D 장면 (건물, 랙, 연결선, 기류, 카메라)
  diagram/    2D 흐름도
  scenario/   사고 시나리오 (registry.ts에 등록)
  ui/         좌우 패널, 투어, 공통 부품(kit.tsx)
  store/      화면 상태 (Zustand)
docs/
  PLAN.md          기획안 · 구현 규칙 · 결정 사항
  research/        조사 자료
  ui-proposal.html UI 개선안 시안
```
